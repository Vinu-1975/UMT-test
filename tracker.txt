7. NEW DATE-RANGE PRESETS
----------------------------------------------------------------
Request: Replace 30d / 90d / YTD / 12 months with
current month, last month, this year, last year.

  - src/lib/types.ts
      RangePreset = "currentMonth" | "lastMonth" | "thisYear"
                  | "lastYear" | "custom"
  - src/lib/filter-context.tsx
      DEFAULT_FILTERS.range = "thisYear"
  - src/lib/filtering.ts
      Removed rangeToMonths().
      Added rangeSlice(filters): [number, number?]
        currentMonth -> [-1]
        lastMonth    -> [-2, -1]
        thisYear     -> [-(currentMonthNumber)]
        lastYear     -> [-12]    (mock fallback)
        custom       -> derived from customFrom/customTo
      filterMonthly / filterMonthlyCad spread the slice.
      rangeWindow() rewritten calendar-aware:
        currentMonth -> 1st of this month -> now
        lastMonth    -> 1st of last month -> last day of last
                        month (day-0 of current month)
        thisYear     -> Jan 1 of this year -> now
        lastYear     -> Jan 1 -> Dec 31 of last year
        custom       -> customFrom/customTo (falls back to YTD)
  - src/components/dashboard/FilterChips.tsx
      RANGES: This month / Last month / This year / Last year /
              Custom
  - src/components/dashboard/ChartFilterChips.tsx
      Same RANGES set
  - src/components/dashboard/ChartFilterPopover.tsx
      RANGE_OPTIONS: Current month / Last month / This year /
                     Last year (Custom handled separately)

14. CHART-CARD BRAND SHADOW (BLUE + GOLD GLOW)
----------------------------------------------------------------
Request: Add a blue/yellow shadow effect to each chart card.
Show it by default (not on hover) and make it strong, then tone
it back down to a softer level.

  - src/index.css
      Added new utility card-brand-shadow (light + .dark
      variants). Two layers per color: a wide soft ambient
      (28px blur, -12px spread) plus a tighter inner glow
      (10px blur, -4px spread). Negative X-offset for the blue
      half (left/bottom), positive X-offset for the gold half
      (right/bottom) so the two brand colors split across
      opposite sides rather than muddying together.
      Light alphas: blue 0.32/0.20, gold 0.38/0.24.
      Dark  alphas: blue 0.45/0.30, gold 0.35/0.22.
      No hover variant — the shadow is always-on by design.
  - src/components/dashboard/ChartCard.tsx
      Single Card className flip: card-hover -> card-brand-shadow.
      card-hover removed at the same site to avoid stacking two
      competing box-shadows.

      on card-hover (out of scope).

16. APPLICATION DONUT — ALL APPS (REMOVE TOP-6 CAP)
----------------------------------------------------------------
Request: Pie chart should include every application, not just
the top 6.

  - src/components/dashboard/charts/ApplicationDonut.tsx
      Removed TOP_N = 6 slicing and the separate tailTotal sum.
      Dataset is now the full sorted application list; grand
      total covers the full set so slice percentages no longer
      divide by an inflated tail-adjusted denominator.
      Added colorAt(i, total) helper:
        First 6 slices use brand palette (--chart-1..6).
        Beyond index 5, colors are generated by walking the
        oklch hue wheel at fixed lightness (0.68) and chroma
        (0.16) with hue step = 360 / (total - 6) + 18° offset
        so every application slice gets a visually distinct
        color even when the count grows past the brand palette.
      Center label "across top 6 apps" -> "across N apps"
      where N is the actual filtered count.
      Legend <ul> now has max-h-[320px] overflow-y-auto pr-1
      and a truncate on the secondary (cad · productLine) text
      so a long application list stays scrollable instead of
      pushing the page layout.
